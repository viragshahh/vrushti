# Vrushti Portfolio

Experimental portfolio site for Vrushti — graphic design, social media, and digital marketing.

## Stack
- Vite
- React + TypeScript
- GSAP
- Lucide Icons

## Local development
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

This first pass intentionally uses placeholder project content. Replace project cards, contact details, social links, and imagery with real resources later.
